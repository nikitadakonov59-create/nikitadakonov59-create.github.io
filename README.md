# Сайт-каталог детского и спортивного оборудования

Демонстрационный проект — многостраничный сайт-каталог для производителя детского игрового и спортивного оборудования.

## 🔗 Живой сайт
https://nikitadakonov59-create.github.io

## Что реализовано
- 15 страниц: главная, каталог, карточка товара, решения, проекты, о компании, контакты, заявка, служебные страницы
- Адаптивная вёрстка (Mobile First)
- Рабочие фильтры в каталоге (по категории, возрасту, материалу, назначению)
- Форма заявки со списком товаров (localStorage)
- Бургер-меню на мобильных
- Плашка cookies (ФЗ-152)
- SEO: title, description, Open Graph, Schema.org, robots.txt, sitemap.xml, favicon

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, CSS-переменные)
- JavaScript (vanilla)
- GitHub Pages (хостинг)

## Структура
- `index.html` — главная
- `catalog.html` — каталог с фильтрами
- `product.html` — карточка товара
- `solutions.html` — решения по объектам
- `projects.html` / `project.html` — проекты
- `about.html` — о компании
- `contacts.html` — контакты
- `request.html` — заявка
- `privacy.html`, `terms.html`, `consent.html`, `cookies.html` — юридические страницы
- `404.html`, `sitemap.html` — служебные
- `css/style.css` — стили
- `js/app.js` — скрипты
- `robots.txt`, `sitemap.xml` — для поисковиков
